A secure full-stack authentication system that allows users to register and log in safely while protecting user data and application routes using React, Node.js, Express.js, and MongoDB.
This project provides a secure authentication system where users can register, log in, and access protected pages after successful authentication. It uses MongoDB with Mongoose to store user information, bcryptjs for password hashing, JWT/session-based authentication, and security features such as input validation, rate limiting, and Helmet to protect the application from common attacks.
Main Features :-
User registration
Secure user login
Password encryption using bcrypt
Protected routes/pages
User session/authentication management
MongoDB database integration
Input validation
Rate limiting for login/API requests
Secure HTTP headers using Helmet
React-based user interface
REST API using Express.js
